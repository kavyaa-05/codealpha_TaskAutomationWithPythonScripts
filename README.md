## 📌 Project Title
**Email Extractor using Python (CodeAlpha Task 3)**


## 📖 Description
This project is a simple automation tool developed using Python that extracts email addresses from a text file. It reads unstructured data, identifies valid email patterns using regular expressions, and stores the extracted emails in a separate output file.
The project demonstrates how automation can simplify repetitive tasks and handle real-world data efficiently.


## ✨ Features
* 📄 Reads input data from a `.txt` file
* 📧 Extracts email addresses using Regular Expressions
* 🧠 Identifies valid email patterns accurately
* 💾 Saves extracted emails into a new file
* ⚡ Fast and efficient processing
* 🔁 (Optional) Removes duplicate emails


## ▶️ How to Run the Project
1. Make sure Python is installed on your system
2. Clone this repository or download the files
3. Place your input file (e.g., `input.txt`) in the project folder
4. Open the folder in VS Code or any IDE
5. Run the script using:
python email_extractor.py
6. Check the output file (e.g., `emails.txt`) for extracted email addresses


## 🛠️ Technologies Used
* 🐍 Python
* 🔍 Regular Expressions (`re` module)
* 📂 File Handling
* 🔤 Strings
