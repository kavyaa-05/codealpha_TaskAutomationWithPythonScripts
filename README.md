📌 Project Title
Email Extractor (Automation Project - CodeAlpha Task 3)


📖 Description
This project is a Python-based automation tool that extracts email addresses from a text file using regular expressions. It reads input data, identifies valid email patterns, and stores them in a separate output file.


✨ Features
📄 Reads data from a text file
📧 Extracts email addresses using regex
🧠 Identifies valid email patterns
💾 Saves extracted emails to a new file
⚡ Simple and efficient automation


▶️ How to Run
python email_extractor.py
🛠️ Technologies Used
Python
Regular Expressions (re)
File Handling
Strings
